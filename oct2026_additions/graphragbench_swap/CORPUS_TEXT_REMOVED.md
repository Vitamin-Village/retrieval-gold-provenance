# GraphRAG-Bench corpus: chunk text not included

GraphRAG-Bench's GitHub repository (GraphRAG-Bench/GraphRAG-Benchmark) and its Hugging Face dataset card declare the MIT License, reproduced in `LICENSE_GraphRAG-Bench.txt`. The questions, answers, evidence sentences and evidence relations in `<split>/qa.jsonl` and `<split>/kg_silver_input.jsonl` are taken from that dataset. Its medical corpus, however, is the text of the NCCN Guidelines (GraphRAG-Bench paper, arXiv 2506.05690), whose copyright the benchmark's license does not clearly cover. The corpus chunks are therefore listed in `corpus_chunks_sha256.jsonl` by id, title, character count and SHA-256 of the UTF-8 text, without the text. The OpenIE KG of each split (`<split>/kg_openie/`) holds the entity and relation phrases extracted from the chunks, which are short spans of the text.

Every statistic of the paper recomputes from the frozen per-question vectors in this folder without the text. The text is needed only to rebuild the chunks or to rerun retrieval, a reader, the OpenIE extraction, or the provenance trace. To rebuild it:

1. Download, from the Hugging Face dataset GraphRAG-Bench/GraphRAG-Bench at revision dc3a111e77dbaf8bbaf51ef331f3cfc9b1b5c546:
   - `https://huggingface.co/datasets/GraphRAG-Bench/GraphRAG-Bench/resolve/dc3a111e77dbaf8bbaf51ef331f3cfc9b1b5c546/Datasets/Corpus/medical.json` -> `paper/external/graphragbench/raw/medical_corpus.json` (SHA-256 12eff34c994dcf101f83968c832bce15dab3c19176da855706f8c9b5cc208758)
   - `https://huggingface.co/datasets/GraphRAG-Bench/GraphRAG-Bench/resolve/dc3a111e77dbaf8bbaf51ef331f3cfc9b1b5c546/Datasets/Questions/medical_questions.json` -> `paper/external/graphragbench/raw/medical_questions.json` (SHA-256 9af76a619e24d84f5509ba10274fbba465e901140a34c4429821f68686f0277b)
2. From the folder that holds `paper/`, run `python paper/eval/build_graphragbench_swap_data.py` (`code/build_graphragbench_swap_data.py`). It writes `paper/external/graphragbench/corpus/passages.jsonl` (SHA-256 0fbbcc93897bf1a08268ec8ddc9316fc47fe49a03c3f723cfea66372301abd69 when run on Windows, whose text mode writes CRLF line ends) and rewrites the split files of this folder (`qa.jsonl`, `kg_silver_input.jsonl` = `kg_silver_input/relations_as_passages.jsonl`) and `build_report.json` with identical content.
3. Check every chunk text against `corpus_chunks_sha256.jsonl` (independent of line ends).
